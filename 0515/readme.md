## 8. 객체와 클래스

객체지향 프로그래밍은 데이터(속성)와 기능(메서드)을 하나의 단위인 '객체'로 묶어 관리하는 방식입니다. 
클래스는 이러한 객체를 찍어내기 위한 '설계도'이며, 설계도를 통해 실제로 메모리에 만들어진 객체를 인스턴스라고 합니다. 
클래스 내부의 __init__() 함수는 객체가 처음 태어날 때 초기 속성을 설정해 주는 생성자 역할을 합니다.

예시
```python
class Dog:
    def __init__(self, name):
        self.name = name 

my_dog = Dog("맥스")      
print(my_dog.name)
```
